# 의상 디자이너 자기소개

10년차 의상 디자이너의 자기소개 원페이지 사이트와, 기업 제출용 자기소개서 3종.

## 구성

| 파일 | 용도 |
|---|---|
| `index.html` · `styles.css` · `script.js` | 다크 테마 원페이지 사이트 |
| `자기소개서-항목형.md` | 국내 기업 채용 양식용 4문항 |
| `자기소개서-커버레터.md` | 브랜드·외국계 직접 지원용 |
| `자기소개서-프로필형.md` | 포트폴리오 앞장 첨부용 |
| `채우기-가이드.md` | 플레이스홀더 42종 기입 가이드 |
| `images/` | 사진 4장 (마크다운·웹 공용) |

## 내용 채우기

이름·브랜드·성과 수치는 전부 `{{...}}` 플레이스홀더로 비어 있습니다.

- **마크다운 문서** — 에디터에서 폴더 전체 찾아바꾸기(VS Code `Ctrl+Shift+H`)
- **웹 사이트** — `script.js` 상단 `PROFILE` 객체의 값만 교체

항목별로 무엇을 쓰면 좋은지는 [채우기-가이드.md](채우기-가이드.md)에 정리돼 있습니다.

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.

## 이미지

사진 4장은 모두 Unsplash 라이선스(상업적 이용 포함 무료)이며 각 이미지에 촬영자 크레딧이 붙어 있습니다.

완성 의상·런웨이 사진은 의도적으로 넣지 않았습니다. 자기소개서에 실린 옷 사진은 읽는 사람이 지원자 작업물로 받아들이기 때문입니다. 본인 작업물을 넣는 방법은 채우기 가이드 6절에 있습니다.
