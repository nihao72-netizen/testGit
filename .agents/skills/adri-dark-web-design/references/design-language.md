# Adri에서 영감을 받은 다크 디자인 언어

이 문서를 템플릿이 아닌 출발점으로 사용한다. Adri에서 참고할 핵심은 신뢰를 먼저 쌓는 여정이다. 간결한 소개에서 작업 방식, 근거, 선별된 작업, 사회적 증거, 명확한 문의 행동, 우려 해소로 이어진다. 이 명료함은 유지하되 현재 주제에 맞는 독창적인 표현을 만든다.

레퍼런스: <https://adri-fluid-demo.squarespace.com/>

## 재해석 원칙

- Adri의 부드럽고 친근한 분위기를 어두운 표면, 따뜻한 밝은 글자, 차분한 라벤더 강조색으로 재해석한다.
- 넉넉한 여백, 직접적인 행동 유도, 이미지 중심의 근거, 명확한 읽기 순서를 유지한다.
- 제품에 맞게 구성, 타이포그래피, 이미지, 시그니처 장치를 바꾼다. 문구, 에셋, 정확한 섹션 배열, 고유한 시각 요소를 복제하지 않는다.
- 여러 효과를 모으기보다 하나의 강한 시각 아이디어를 선택한다.

## 기본 색상 토큰

프로젝트에 기존 팔레트가 없을 때만 다음 값을 사용한다. 의미적 역할과 접근 가능한 명암비를 유지하면서 브랜드에 맞게 조정한다.

```css
:root {
  --color-canvas: #0d0b12;
  --color-surface: #17131f;
  --color-surface-raised: #211a2c;
  --color-text: #f5f1f7;
  --color-text-muted: #b9b0c3;
  --color-border: #3a3147;
  --color-accent: #b6a1e8;
  --color-accent-strong: #d2c3f5;
  --color-on-accent: #16111d;
}
```

- 캔버스는 순수한 검정 대신 차콜에 가깝게 설정해 무거운 그림자 없이 표면을 구분한다.
- 밝게 솟은 플럼 표면은 내비게이션, 대표 작업, 컨트롤 또는 하나의 핵심 전환 영역에만 절제해 사용한다.
- 라벤더는 포커스, 주요 행동, 선택 상태, 소수의 구조적 단서에만 사용한다.
- 단색 면과 가는 테두리를 우선한다. 제품의 의미를 전달하거나 사용자가 명시적으로 요청한 경우가 아니면 그라디언트를 추가하지 않는다.

## 타이포그래피

- 글꼴 패밀리는 최대 두 개만 사용한다. 개성 있는 에디토리얼 서체는 짧은 디스플레이 문구에, 차분한 산세리프는 본문과 컨트롤에 사용한다.
- 프로젝트의 기존 글꼴을 우선한다. 외부 글꼴을 사용할 수 있고 기존 타이포그래피가 없다면 절제된 디스플레이용 `Newsreader`와 본문용 `DM Sans`를 출발점으로 고려할 수 있지만 필수는 아니다.
- 히어로 제목은 위계를 세울 만큼 크게 하되 줄 길이를 제어한다. 디스플레이 한 줄은 약 8~12단어, 본문 한 줄은 약 55~75자를 목표로 한다.
- 기본적으로 문장형 대소문자를 사용한다. 적당한 자간의 대문자는 짧은 유틸리티 라벨에만 쓰고 긴 문단에는 사용하지 않는다.
- 적절한 경우 `clamp()`로 유동적인 글자 크기 체계를 만들고, 글자를 무조건 줄이는 대신 좁은 화면에서 줄바꿈을 확인한다.

## 레이아웃과 콘텐츠 흐름

12열 데스크톱 그리드, 6열 태블릿 그리드, 4열 모바일 그리드를 출발점으로 삼되 기존 시스템에 맞게 조정한다.

```text
데스크톱
+---------------- 헤더 / 명확한 주요 행동 ----------------+
| 핵심 주장과 근거 문구       주제에 맞는 대표 시각 요소     |
+---------------------------------------------------------+
| 접근 방식 / 가치            근거 또는 역량                |
+---------------- 선별 작업, 증거 또는 제품 ----------------+
| 사회적 증거                 다음 행동                     |
+---------------- 우려 해소 / 자주 묻는 질문 ---------------+
+---------------- 차분한 푸터 ------------------------------+

모바일
+--------- 헤더 ---------+
| 핵심 주장              |
| 주요 행동              |
| 대표 시각 요소 / 근거  |
| 가치와 증거            |
| 선별 작업              |
| 사회적 증거            |
| 우려 해소 + 행동 유도  |
+--------- 푸터 ---------+
```

- 이 순서는 설득 모델이지 반드시 따라야 하는 섹션 목록이 아니다. 페이지의 역할에 따라 순서를 바꾸거나 일부를 생략한다.
- 히어로나 선별 작업 영역에서는 비대칭을 활용하고, 읽을 내용이 많은 영역에서는 안정적인 리듬으로 돌아온다.
- 충분한 세로 여백과 소수의 간격 토큰을 사용한다. 라벨과 설명 대상이 서로 멀어지는 무의미한 빈 공간은 만들지 않는다.
- 이미지마다 의도적인 종횡비와 초점을 설정한다. 서로 바꿔 끼워도 구분되지 않는 스톡 이미지 카드 그리드를 피한다.
- 모바일에서는 이야기 순서를 보존하고 주요 행동을 핵심 주장 가까이에 둔다. 우선순위 조정 없이 데스크톱 구성을 단순히 세로로 쌓지 않는다.

## 행동과 상호작용

- 하나의 행동에 분명한 최우선 강조를 부여한다. 보조 행동은 일반적으로 텍스트 링크나 차분한 외곽선 컨트롤로 표현한다.
- 모든 컨트롤, 태그, 컨테이너를 알약 모양으로 만들지 말고 비율을 의도한 둥근 사각형을 사용한다.
- 가능한 경우 터치 영역을 최소 44×44 CSS 픽셀로 유지한다.
- 간격을 둔 2px 라벤더 외곽선처럼 눈에 잘 보이는 포커스 처리를 사용하고 모든 표면에서 보이는지 확인한다.
- 컨트롤은 결과가 드러나게 이름 붙인다. 모호한 “제출”이나 “더 알아보기” 대신 “상담 예약”, “사례 보기”, “변경 사항 저장”처럼 작성한다.

## 시그니처와 모션

주제에서 자연스럽게 나온 시그니처 하나를 선택한다. 에디토리얼 이미지 크롭, 근거를 잇는 연속 라벤더 선, 과감한 타이포그래피 디테일, 프로젝트 소재를 정교하게 드러내는 방식 등이 될 수 있다. 서로 무관한 페이지에 같은 시그니처를 기계적으로 반복하지 않는다.

짧은 히어로 등장이나 절제된 사례 공개처럼 하나의 조율된 순간을 우선한다. 일반적인 호버 전환은 120~220ms로 유지하고, 스크롤 가로채기를 피하며, `prefers-reduced-motion: reduce`에서는 필수적이지 않은 변형과 투명도 시퀀스를 비활성화한다.

## 전형적인 결과 피하기

- 기본값처럼 쓰는 유리 패널, 빛나는 네온 테두리, 장식용 데이터 차트, 과도한 블러 배경을 사용하지 않는다.
- 무분별한 벤토 그리드, 반복되는 둥근 카드, 정보 목적이 없는 알약 모양 라벨을 사용하지 않는다.
- 배경이 어둡다는 이유만으로 애시드 그린을 강조색으로 사용하지 않는다.
- 제품의 세계관에 근거하지 않은 거대한 그라디언트 제목이나 떠다니는 장식 구체를 사용하지 않는다.
- 순서가 실제 과정, 시퀀스, 위계를 전달하지 않는다면 섹션에 번호를 붙이지 않는다.
- 꾸며낸 성과, 고객 로고, 후기, 통계를 사실처럼 제시하지 않는다.

## 검토 체크리스트

- 히어로가 페이지의 주제와 방문자가 계속 살펴볼 이유를 설명한다.
- 색상 토큰에 의미가 있고 일관되게 재사용되며 WCAG AA 목표에서 읽을 수 있다.
- 불필요한 글꼴 패밀리나 굵기 없이 디스플레이와 읽기 역할이 구분된다.
- 모든 요소가 시선을 다투지 않아도 주요 행동이 분명하다.
- 시그니처가 이 주제에 속하며 모든 장식 요소에 존재 이유가 있다.
- 키보드 탐색, 포커스 표시, 대체 텍스트, 모션 감소, 모바일 읽기 순서가 올바르게 동작한다.
- 레퍼런스의 표현을 복제하지 않으면서 명료함과 따뜻함을 전달한다.
